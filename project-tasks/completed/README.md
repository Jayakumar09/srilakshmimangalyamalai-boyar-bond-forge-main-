# Completed Tasks (Archive)

Tasks whose work is **committed, pushed and verified on GitHub**.

Each folder preserves the permanent record: source/migration references, test
harnesses, evidence, SHA-256 checksums and the closing commit(s). Do not delete
or rewrite an archived record; append corrections instead.

Retrospectively created records (e.g. T3/T4/T5, whose verification predates this
system) are labelled as such inside their `TASK.md`.
